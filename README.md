# Hańńá boade gáddáj

En sangbok som webapp, med sangene fra *Hańńá boade gáddáj – Lávllagirjje* (Th. Blaasværs Forlag, 1990), på lulesamisk. Den kjøres fra GitHub Pages og virker i moderne nettlesere på mobil, nettbrett og datamaskin. Den kan installeres som en app (PWA) og brukes helt uten nett.

**Åpne sangboken:** https://hanna-boade-gaddaj.github.io/

## Funksjoner

- **Søk på nummer:** skriv f.eks. `17` og trykk Enter, så åpnes sangen.
- **Søk på ord:** skriv ett eller flere ord, f.eks. `biejvve` eller `Jesus`. Treffene viser hvilket vers ordet står i, og ordene er uthevet i sangen. Du kan søke uten samisk tastatur: `a` finner også `á`, og `n` finner `ń` (f.eks. `hanna` finner «Hańńá»). Navn på forfattere og oversettere gir også treff.
- **Hele sangen** vises med nummererte vers, omkved (Kor) markert og repetisjonstegn (:/:), og med opphav (tekst, melodi, oversettelse) under.
- **Bla** til forrige og neste sang, og velg **tekststørrelse** (A / A).
- **Sist åpnet** blir husket på enheten.
- **Direkte lenke** til en sang: https://hanna-boade-gaddaj.github.io/#17
- **Offline:** etter første besøk kan sangboken brukes uten nett.

## Bruk og installering

| Enhet | Slik installerer du |
|---|---|
| **iPhone / iPad** | Åpne adressen i Safari, trykk **Del** (firkant med pil opp) og velg **Legg til på Hjem-skjerm** |
| **Android** | Åpne adressen i Chrome, åpne menyen **⋮** og velg **Installer app** eller **Legg til på startsiden** |
| **Mac / Windows / Linux** | Åpne adressen i Chrome eller Edge og klikk installer-ikonet i adressefeltet. I Safari på Mac: **Fil → Legg til i Dock** |

Åpne sangboken én gang mens du har nett. Etter det virker den offline.

## Om filene

Sangtekstene er skrevet av fra en skannet utgave av heftet. Alt (tekst, skrift, kode) ligger i `index.html`, uten eksterne avhengigheter. Fargene er hentet fra omslaget. Skrifttypen er Source Sans 3 (SIL Open Font License).
